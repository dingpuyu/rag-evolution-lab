# PulseCare 客户入门与提问指南

> 合成测试资料：只用于知识检索与 Agent 体验，不用于真实设备操作。

## 第一次使用先做什么

不需要先懂专业术语。按下面顺序收集四项信息即可：

1. **完整型号**：VSM-100、VSM-100 Pro 或 VSM-200。
2. **软件版本**：例如 2.6.1 或 3.1，尽量包含补丁版本。
3. **你看到的现象**：例如“找不到 Wi-Fi 菜单”或“日志导出失败”。
4. **屏幕上的错误码**：例如 SYS-NET-042 或 LOG-EXP-215；没有错误码可以写“无”。

型号和软件版本可在本项目虚构的 `设备中心 → 关于 → 设备信息` 页面查看。测试标签上的 DI 也能帮助确认型号，但不能代替完整型号。

## 不知道怎么问时可以照着说

- “我对产品完全不了解，请先介绍有哪些型号。”
- “VSM-100 和 VSM-100 Pro 有什么区别？”
- “我的型号是 VSM-200，软件 3.1，网络连不上，应该先检查什么？”
- “我看到 SYS-NET-042，但不知道设备型号。”
- “我在哪里能找到型号和软件版本？”

Agent 会逐步询问缺少的信息。产品介绍和型号对比不强制要求先提供型号；具体错误码、菜单路径、兼容性和排障步骤则必须先确认型号，必要时还要确认版本。

## 回答如何理解

- **已回答**：知识库中找到了适用型号和版本的公开依据。
- **需要澄清**：还缺型号、版本、错误码或现象，不代表设备一定有故障。
- **已拒答**：问题涉及临床诊断、治疗或患者参数，超出客户知识助手边界。
- **引用证据**：可以展开查看来源文件、章节、版本和相关片段。

## 客户与专业运维资料的边界

客户知识助手只读取公共产品资料，不读取医院、服务商或租户的内部 Runbook、工单队列、连接器地址和内部处置流程。需要内部操作时，应联系有权限的设备运维人员。
