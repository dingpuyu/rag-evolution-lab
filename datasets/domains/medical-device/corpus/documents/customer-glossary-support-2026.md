# PulseCare 客户术语与支持升级说明

> 合成测试资料：用于帮助零基础用户理解检索结果。

## 常用术语

- **型号**：设备的完整产品名称，例如 VSM-100 Pro；`Pro` 不能省略。
- **软件版本**：设备软件的版本号，例如 2.6.1。主版本、次版本和补丁版本可能影响答案。
- **DI**：本项目虚构的设备标识，用于辅助确认型号。
- **错误码**：设备显示的结构化故障标识，例如 SYS-NET-042。
- **兼容性矩阵**：说明某型号、版本和配件能否组合使用的表格。
- **现场更正通知**：带有严格型号、版本和批次范围的受控通知，不能只凭相似名称判断是否适用。
- **Runbook**：组织内部的运维手册。客户 Agent 不读取租户私有 Runbook。
- **引用**：Agent 回答所依据的知识片段，可用于核对来源、章节和版本。

## 联系支持前建议准备的信息

准备完整型号、软件版本、设备标识、批次（如适用）、错误码、现象描述、首次出现时间，以及已经完成的非侵入式检查。不要上传患者信息、真实医疗数据、账号密码或访问令牌。

## Agent 能做和不能做的事

Agent 可以介绍虚构产品线、解释型号差异、引导查找设备信息、依据公开资料提供非侵入式排障步骤，并说明何时应升级给专业人员。

Agent 不能作出临床诊断、治疗建议、患者参数设置、真实采购结论，也不能读取或泄露租户内部 Runbook、工单和连接器信息。
