# 医疗设备销售合规核验：国家药监局 UDI 数据库

> 来源：国家药品监督管理局医疗器械唯一标识数据库。采集日期：2026-08-17。

## 数据库作用

国家药监局医疗器械唯一标识数据库公开医疗器械产品标识及相关信息。注册人或备案人负责上传、维护数据，并对真实性、准确性和完整性负责。数据库面向公众、经营企业和医疗机构提供查询与共享能力。

## 销售业务如何使用

1. 用产品标识、产品名称或企业名称在 UDI 数据库查询。
2. 核对产品名称、规格型号、注册人/备案人、注册或备案证号、产品类型及数据状态。
3. 对照厂商最新产品页、注册证和正式配置单，避免把海外型号、历史型号或不同配置混为一谈。
4. 报价、投标和签约前再次核验，并保留核验时间与证据快照。
5. 需要批量主数据时，可使用官方全量/月/周/日下载；正式共享 API 需要按官方流程申请授权。

## 官方入口

- 在线查询：https://udi.nmpa.gov.cn/
- 数据下载：https://udi.nmpa.gov.cn/download.html
- 数据共享说明：https://udi.nmpa.gov.cn/toDetail.html?CatalogId=3&infoId=40
- 对接说明：https://udi.nmpa.gov.cn/showInterrRead.html

## 边界

UDI 数据是合规主数据的重要来源，但不能单独证明某一配置当前有货、适合某个科室或满足某次招标。最终结果必须由销售、法规和厂商共同复核。
