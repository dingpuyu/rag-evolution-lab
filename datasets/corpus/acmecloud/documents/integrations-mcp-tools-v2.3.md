# 工具与 MCP 集成

## 工具注册

工具必须声明稳定的名称、版本、输入 JSON Schema、超时时间和副作用等级。只读工具可以自动执行，写工具必须标记为需要确认。

## 身份传递

调用链通过短期 Credential 传递租户和 Scope，工具服务端再次校验资源归属。不能信任模型生成的 tenant_id、role 或 allowlist 字段。

## 超时与重试

工具调用超过 5 秒先进入超时状态，幂等的只读调用最多重试一次；写操作不自动重试。每次调用都记录 tool_call_id、输入摘要、状态和耗时。

## MCP 边界

MCP Server 只暴露经过审核的工具集合，禁止把数据库连接、任意 Shell 和内部网络探测能力直接交给 Agent。工具返回结果应经过 schema 校验和敏感信息过滤。
