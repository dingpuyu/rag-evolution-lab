# Webhook 集成规范

## 请求签名

Webhook 请求使用 `X-Acme-Signature` 传递 HMAC-SHA256 签名，签名原文为时间戳、HTTP 方法、路径和原始请求体的拼接结果。接收方必须先校验时间戳，再使用常量时间比较校验签名。

## 幂等处理

每个事件都带有唯一 `event_id`。接收方应在完成业务处理前记录 event_id，并对重复投递返回 2xx；不能因为重试再次创建工单、扣款或发送通知。

## 重试策略

接收方返回 2xx 表示成功。5xx 或网络超时会按 1、2、4、8 分钟退避，最多重试 6 次；4xx 默认不重试，除非修复鉴权后由运营人员手动重放。

## 安全边界

Webhook Endpoint 必须使用 HTTPS，并限制来源 IP 或 mTLS。不要把签名密钥、Authorization Token 和内部错误堆栈写入回调响应。
