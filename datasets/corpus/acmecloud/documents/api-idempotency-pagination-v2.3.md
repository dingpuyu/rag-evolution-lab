# API 幂等与分页

## 幂等键

创建订单、导出任务和凭证等写请求必须携带 `Idempotency-Key`。相同租户、相同接口和相同幂等键在 24 小时内返回第一次请求的结果，不得重复执行副作用。

## 分页规则

列表接口默认使用 cursor 分页，响应中的 `next_cursor` 为空表示已经到达末页。cursor 只允许原样回传，不能把 offset 与 cursor 混用。

## 一致性

创建资源后立即查询可能处于最终一致窗口。客户端应使用响应中的资源 ID查询，并在收到 404 时按文档规定短暂重试，而不是再次提交创建请求。

## 错误处理

`400` 表示请求格式错误，`401` 表示凭证无效，`403` 表示权限不足，`409` 表示版本冲突。只有明确标记为可重试的 429、502、503 才允许自动重试。
