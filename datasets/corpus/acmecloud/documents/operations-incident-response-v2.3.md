# 生产故障响应

## 事件分级

P0 表示核心服务完全不可用，P1 表示主要功能大面积受影响，P2 表示局部功能退化，P3 表示一般咨询或低风险缺陷。分级以用户影响和恢复时限为准，不以单条日志数量判断。

## 响应流程

发现异常后先创建事件并记录 trace_id，指定事件负责人、沟通负责人和技术负责人。先执行只读检查，再决定是否回滚；任何会改变数据的动作都必须经过值班负责人确认。

## 沟通与复盘

P0/P1 事件每 30 分钟更新一次状态，恢复后 5 个工作日内完成复盘。复盘至少包含时间线、影响范围、根因、检测缺口和改进项，不得把用户隐私或密钥复制到报告。

## Agent 边界

Agent 可以查询当前状态、最近事件和已批准的运行手册，但不能自行执行重启、扩容、回滚或删除数据等高风险工具调用。
