# ADR-0001：使用 Go 作为在线服务主语言

- 状态：Accepted
- 日期：2026-07-15

## 背景

项目目标是探索 Agent/RAG 应用的工程实践，同时需要支持并发 API、流式响应、可测试组件和后续复用。

## 决策

在线服务、CLI、检索 Pipeline 和主要测试使用 Go。Python 只用于离线分析和可选的第三方评测框架。

## 原因

- 与现有 Go Agent 开发经验连续。
- 适合构建明确接口和确定性单元测试。
- 便于展示服务端并发、超时和可观测性。
- 避免为了生态便利把整个项目切换到 Python。

## 影响

- 部分 RAG 库需要自行封装或通过 API 接入。
- Python 评测结果必须与 Go 产生的 Trace 和数据格式保持一致。
